Відповіді на контрольні запитання

3. Що таке селектори в CSS? Наведіть приклади різних типів селекторів.

Селектор вказує, до яких HTML-елементів застосувати правило. Приклади:

  • селектор елемента: h1 { }
  • селектор класу: .card { }
  • селектор ідентифікатора: #about { }
  • універсальний селектор: * { }
  • селектор нащадка: div p { }
  • групування: h1, h2 { }
  • псевдоклас: a:hover { }
  • селектор атрибута: input[type="text"] { }

4. Яка різниця між класовим та ідентифікаторним селекторами?

Клас (.name) можна призначати багатьом елементам, і один елемент може мати кілька класів. Ідентифікатор (#name) має бути унікальним на сторінці: його отримує лише один елемент. Ідентифікатор має вищу специфічність, тому його стилі переважають над стилями класу.
